# JARVIS

Локальный голосовой ассистент. Всё работает на твоём компьютере, интернет не нужен
после установки. Ни ключей API, ни подписок, ни телеметрии.

```
микрофон ──► Whisper ──► Qwen 2.5 3B ──► Piper ──► колонки
  (PipeWire)  (whisper-server)  (llama-server)  (onnx)   (PipeWire)
```

## Железо

Проверено на: Archcraft, i5-12400F, RTX 3050 6 ГБ, 32 ГБ RAM, Python 3.14, USB-микрофон.
Занимает ~3 ГБ на диске. Задержка от конца фразы до начала ответа — около 3 секунд.

## Установка

```bash
cd ~/Vulkan/jarvis

sudo bash install.sh      # системные пакеты Arch
bash setup.sh             # Python-окружение
bash fetch-models.sh      # модели, ~2.7 ГБ
```

## Запуск

```bash
./run.sh
```

Говоришь — он отвечает. `Ctrl+C` — выход.

## Состав

| Слой | Что используется | Зачем |
|------|------------------|-------|
| Захват звука | `pw-cat` (PipeWire) | без portaudio, напрямую в ядро |
| Распознавание | `whisper-server`, модель small, CPU | русский, ~2.8 с на фразу |
| Мозг | `llama-server`, Qwen2.5-3B Q4_K_M, Vulkan | сильный русский, 58 ток/с на GPU |
| Голос | Piper, `ru_RU-dmitri-medium` | офлайн, быстро, естественно по-русски |

## Что выяснилось при настройке

Проверенные на практике выводы — чтобы не пришлось повторять эксперименты.

**Vulkan для LLM — да, для Whisper — нет.** Энкодер Whisper на ggml-vulkan
отработал за 5223 мс, на CPU — за 535 мс. Разница в десять раз не в пользу GPU:
бэкенд на драйвере NVIDIA для этого слоя медленный. Поэтому Whisper запущен
с `-ng` (CPU), а GPU отдан LLM — там Vulkan даёт 96% загрузки карты и 58 ток/с.

**VAD — единственное, что реально улучшило распознавание.** Whisper на цифровой
тишине выдаёт «Редактор субтитров Н.Закомолдина», на шуме — «звук птиц».
Это фантомные реплики, из-за которых ассистент отвечает на пустоту.
С silero-VAD тишина и шум дают пустой ответ за 0.05 с вместо 2.8 с — отсекаются
до энкодера. На настоящей речи вреда нет.

**Модель `small` точнее, чем кажется — увеличивать её не нужно.** На одинаковых
записях: `small` — идеально и на чистом, и на сильно зашумлённом; `medium` —
то же самое, но втрое медленнее (10 с против 3.1 с на фразу); `ru-small`,
дообученная на русском, — хуже универсальной («Привет джарвисов»).
Все три проверены, лишние удалены, осталась `small`.

**Громкость микрофона значения не имеет.** Whisper безупречно разобрал запись,
приглушённую в 20 раз. Нормализация уровня не нужна.

**Подсказка декодеру (`--prompt`) вредит.** Список ожидаемых слов подталкивал
модель вставлять их в фразы, где их не было. Убрана.

**Модель должна жить в памяти.** Через `whisper-cli` каждая фраза стоила
~20 секунд, из которых 13 — чтение 487 МБ модели с диска. `whisper-server`
держит модель в RAM: 2.8 с.

**Самослух.** Джарвис слышит собственный голос через колонки и начинает
отвечать себе. После озвучки порог VAD поднимается в 2.5 раза на 3 секунды
(`ECHO_GUARD` в `modules/audio.py`). С наушниками проблемы нет вовсе.

## Что он умеет

13 действий, выбираются моделью через function calling:

| | |
|---|---|
| `open_app` | firefox, терминал, файлы, калькулятор, gimp |
| `open_url` / `web_search` | открыть сайт, поиск в интернете |
| `system_info` | время, дата, память, диск, видеокарта, загрузка, аптайм |
| `volume` | громче, тише, выключить, установить уровень |
| `screenshot` | экран, окно, выделенная область |
| `windows` | список окон, переключиться, закрыть |
| `power` | блокировка, сон, выключение, перезагрузка |
| `notify` | уведомление на экране |
| `add_note` / `read_notes` | заметки в `notes.md` |
| `set_timer` / `cancel_timers` | таймер с голосовым объявлением |
| `list_apps` | какие программы установлены |

Примеры: «открой firefox», «запусти терминал», «найди в интернете рецепт борща»,
«запиши заметку купить молоко», «поставь таймер на десять минут»,
«переключись на окно 2», «сделай скриншот», «выключи звук».

**Безопасность.** Модель не может выполнить произвольную команду — она выбирает
только из белого списка. Никакого `shell=True` с текстом от модели. Выключение
и перезагрузка требуют явного подтверждения: Джарвис сначала спрашивает, и только
после твоего «да» выполняет.

**Добавить своё действие** — допиши функцию в `modules/tools.py`, зарегистрируй
в `SCHEMAS` и `HANDLERS`. Больше ничего менять не нужно.

## Характер

Лежит в `config/persona.md`. Правь свободно — это обычный текст.
Сейчас там: сухой и саркастичный голос из кино, мужская форма, обращается
к тебе как к Александру.

## Структура

```
jarvis.py              главный цикл: слушаю → думаю → говорю
modules/audio.py       микрофон, VAD с калибровкой, защита от самослуха
modules/stt.py         Whisper (сервер, CPU, silero-VAD)
modules/llm.py         llama-server, function calling, история диалога
modules/tools.py       13 действий: белый список команд
modules/tts.py         Piper
config/persona.md      характер
notes.md               заметки
models/                модели (~2.7 ГБ)
logs/                  логи серверов
```

## Запуск

```bash
./run.sh                    # обычный режим, с микрофоном
./run.sh --file реплика.wav # проверка без микрофона: файл → ответ
```

## Настройка

Поменять голос — в `jarvis.py`, переменная `VOICE`: `dmitri`, `denis`, `ruslan`, `irina`.
Скорость речи — `length_scale` в `modules/tts.py`.
Чувствительность микрофона — `SENSITIVITY` и `MIN_RMS` в `modules/audio.py`.
Глубина памяти диалога — `HISTORY_LIMIT` в `jarvis.py`.

## Проблемы

**Не слышит** — `python modules/audio.py` покажет источники. Если там только
`.monitor`, PipeWire не подхватил микрофон.

**Отвечает сам себе** — `ECHO_GUARD` в `modules/audio.py`. Убери колонки
из зоны слышимости микрофона или надень наушники.

**Долго думает** — `logs/llama-server.log`. Первый ответ всегда ~15 с
(сервер прогревается), дальше 0.5–1.3 с.

**Не говорит** — проверь голос:
`echo тест | .venv/bin/python -m piper -m models/tts/ru_RU-dmitri-medium.onnx -f /tmp/t.wav`
