# JARVIS

Локальный голосовой ассистент. Всё работает на твоём компьютере: после установки
интернет не нужен, ключей API нет, телеметрии нет.

```
микрофон ──► Whisper ──► Qwen 3 8B ──► Piper ──► колонки
  (PipeWire)  (whisper-server)  (llama-server)  (onnx)   (PipeWire)
```

## Проверено на

Archcraft, i5-12400F, RTX 3050 6 ГБ, 32 ГБ RAM, Python 3.14, USB-микрофон.
Занимает ~8 ГБ на диске. Задержка голос-в-голос около 3 секунд.

## Установка

```bash
cd ~/Vulkan/jarvis

sudo bash install.sh      # системные пакеты Arch
bash setup.sh             # Python-окружение
bash fetch-models.sh      # модели
```

## Запуск

```bash
./run.sh                    # обычный режим, с микрофоном
./run.sh --file реплика.wav # проверка без микрофона: файл → ответ
```

## Состав

| Слой | Что используется | Замер |
|------|------------------|-------|
| Захват звука | `pw-cat` (PipeWire) | без portaudio, прямо в ядро |
| Распознавание | `whisper-server`, small, CPU, silero-VAD | WER 19.3%, 2.8 с на фразу |
| Мозг | `llama-server`, Qwen3-8B Q4_K_M, Vulkan | 26 ток/с, VRAM 5387/6144 МиБ |
| Голос | Piper, `ru_RU-dmitri-medium` | 1.6 с синтез |

## Что он умеет

14 действий, модель выбирает их сама через function calling. На Qwen3-8B
проверены все 14 из 14 — вызовы верные.

| | |
|---|---|
| `open_app` | firefox, терминал, файлы, калькулятор, gimp |
| `open_url` / `web_search` | открыть сайт, поиск в интернете |
| `system_info` | время, дата, память, диск, видеокарта, загрузка, аптайм |
| `volume` | громче, тише, выключить, установить уровень |
| `screenshot` | экран, окно, выделенная область |
| `windows` | список окон, переключиться, закрыть |
| `power` | блокировка, сон, выключение, перезагрузка |
| `notify` | уведомление на экране |
| `add_note` / `read_notes` | заметки в `notes.md` |
| `set_timer` / `cancel_timers` | таймер с голосовым объявлением |
| `list_apps` | какие программы установлены |

Примеры: «открой firefox», «запусти терминал», «найди в интернете рецепт борща»,
«запиши заметку купить молоко», «поставь таймер на десять минут»,
«переключись на окно 2», «сделай скриншот», «выключи звук».

**Безопасность.** Модель не может выполнить произвольную команду — она выбирает
только из белого списка. Никакого `shell=True` с текстом от модели. Выключение
и перезагрузка требуют явного подтверждения.

**Добавить своё действие** — допиши функцию в `modules/tools.py`, зарегистрируй
в `SCHEMAS` и `HANDLERS`. Больше ничего менять не нужно.

## Характер

`config/persona.md` — обычный текст, правь свободно. Сухо, саркастично, без
Markdown и смайликов, мужская форма, обращается к тебе как к Александру.

## Структура

```
jarvis.py              главный цикл: слушаю → думаю → говорю
modules/audio.py       микрофон, Endpoint (начало и конец реплики), защита от самослуха
modules/stt.py         Whisper: сервер, CPU, silero-VAD
modules/llm.py         llama-server, function calling, история диалога
modules/tools.py       14 действий в белом списке
modules/turn.py        Smart Turn v3 — есть в проекте, но выключен (см. ниже)
modules/tts.py         Piper
config/persona.md      характер
tests/                 стенд замеров качества
logs/                  логи серверов
```

## Стенд замеров

Качество не оценивается на глаз — есть воспроизводимые тесты.

```bash
.venv/bin/python tests/make_corpus.py   # собрать 18 записей (6 сценариев × 3 шума)
.venv/bin/python tests/bench_stt.py     # WER и время распознавания
.venv/bin/python tests/bench_turn.py    # где обрывается реплика на паузе
.venv/bin/python tests/sweep_silence.py # подбор паузы окончания
```

Записи синтезируются голосом Piper, поэтому набор воспроизводится на любой машине.

## Что выяснилось при настройке

Всё это измерено, а не взято из документации.

**Vulkan для LLM — да, для Whisper — нет.** Энкодер Whisper на ggml-vulkan
отработал за 5223 мс, на CPU — за 535 мс. Разница в десять раз не в пользу GPU.
Проверено на двух размерах модели: на Vulkan время постоянное (~5.2 с хоть для
466 МБ, хоть для 548 МБ), то есть упирается не в вычисления. GPU отдан LLM.

**Модель `small` точнее, чем кажется — увеличивать её не нужно.** На одинаковых
записях `small` идеальна и на чистом, и на зашумлённом; `medium` — то же самое
втрое медленнее; `ru-small`, дообученная на русском, хуже универсальной.
Все три проверены, лишние удалены.

**VAD убирает галлюцинации.** Whisper на цифровой тишине выдаёт «Редактор
субтитров Н.Закомолдина», на шуме — «звук птиц». С silero-VAD тишина даёт пустой
ответ за 0.05 с вместо 2.8 с: отсекается до энкодера. На речи вреда нет.

**Пауза окончания реплики подобрана перебором.** При 0.7 с фраза рвалась
в 2 случаях из 9: «Открой пожалуйста браузер, [пауза] и найди рецепт борща»
теряла вторую половину. При 1.1 с — 0 из 9, цена +0.39 с к отклику.

**Smart Turn v3 не заработал.** Модель подключена (`modules/turn.py`, 8.3 МБ,
BSD-2-Clause), признаки считаются точно как в `transformers.WhisperFeatureExtractor`.
Но вероятность «реплика закончена» колеблется в диапазоне 0.02, и порог поставить
негде. Похоже, модель ждёт реальную человеческую речь, а не синтез Piper.
Код оставлен, но по умолчанию выключен.

**3B → 8B дало качественный скачок.** На шести одинаковых вопросах 8B отвечает
связнее, держит характер и не выдумывает. 3B в тех же тестах ломался:
обращался «братан», вставлял смайлик `😔`, выдавал Markdown списком и один раз
вставил китайские иероглифы — «Ты так叫我, Александр». Скорость при этом
упала: суммарно 17.9 с против 14.0 с на шесть вопросов (+28%).

**Qwen3 рассуждает вслух.** По умолчанию заполняет `reasoning_content`, а в
`content` отдаёт пустоту. Лечится `chat_template_kwargs: {"enable_thinking": false}`.

**Модель может соврать о выполненном действии.** На мусном распознавании
инструмент не вызвался, а ответ был «Заметка записана». Усилено правилом в
системном промпте; на мусном вводе теперь отвечает «Не понял, что записать».

**Громкость микрофона значения не имеет.** Whisper безупречно разобрал запись,
приглушённую в 20 раз. Нормализация уровня не нужна.

## Настройка

Голос — `VOICE` в `jarvis.py`: `dmitri`, `denis`, `ruslan`, `irina`.
Скорость речи — `length_scale` в `modules/tts.py`.
Чувствительность микрофона — `SENSITIVITY`, `MIN_RMS`, `VAD_SILENCE` в `modules/audio.py`.
Модель и контекст — `MODEL_NAMES`, `N_CTX` в `modules/llm.py`.
Глубина памяти диалога — `HISTORY_LIMIT` в `jarvis.py`.

## Проблемы

**Не слышит** — `.venv/bin/python modules/audio.py` покажет источники.

**Отвечает сам себе** — `ECHO_GUARD` в `modules/audio.py`. Убери колонки из
зоны слышимости микрофона или надень наушники.

**Долго думает** — `logs/llama-server.log`. Первый ответ ~15 с (прогрев),
дальше 1.5–4 с.

**Не влезает модель в VRAM** — 8B занимает 5387 МиБ из 6144. Убрав её из
`MODEL_NAMES` в `modules/llm.py`, вернётся 3B.

**Слышит собственное имя неверно** — «Джарвис» он слышит как «Джаркис» или
«Джаррис». Подсказка декодеру `--prompt` не помогает, вредна. Пока не решено.
